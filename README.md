# 회비 산출·검증 자동화 프로그램

자동이체통합관리업무의 회비 산출에서 **실적 집계 → 회비 계산 → 검증 → 기관별 자료 생성 → 담당자 메일 발송**을
한 번에 처리합니다. 기존의 피벗테이블·계산파일 복사·한글 파일 붙여넣기·2인 교차검증 작업을 대신합니다.

## 주요 기능

| 기능 | 내용 | 결과물 |
|---|---|---|
| ① 실적 데이터 자동 집계 | 로우데이터 시트별로 기관코드 피벗 → 계산파일 양식에 항목별 입력, 합계·단수조정 수식 입력 | `계산파일_결과.xlsx`, `피벗_검토.xlsx` |
| ② 산출 기준 설정·재사용 | 파일/전문 → 항목 규칙, 회비 총액·비율·기관 수, 검증 기준을 설정 파일 하나로 관리 | `config/mapping.toml` |
| ③ 산출 결과 자동 검증 | 내부 정합성 검사, 전기 대비 이상치, 계산파일 수식 결과와 프로그램 계산 교차검증 | `검증결과.xlsx` |
| ④ 기관별 산출자료 자동 생성 | 기관별 회비·상세 실적 엑셀, 한글용 산출내역 문서, 전체 요약 | `기관별/*.xlsx`, `산출내역_한글용.docx`, `산출결과_요약.xlsx` |
| 담당자 메일 발송 | 등록된 담당자에게 기관별 자료 첨부 메일 (기본은 미리보기) | `메일/` |

## 설치

Python 3.11 이상이 필요합니다.

```bash
pip install -r requirements.txt
```

교차검증(계산파일 수식을 실제로 계산해 비교)을 하려면 [LibreOffice](https://www.libreoffice.org/)를 설치하세요.
없으면 교차검증만 '생략'으로 표시되고 나머지는 그대로 동작합니다.

## 사용법

### 1. 회비 산출

```bash
python -m calc_fee run --raw 로우데이터.xlsx --template 계산파일.xlsx --period "2026년 3분기" --out-dir out/2026Q3
```

지난 산출 결과와 비교하려면 `--prev` 에 지난번 `산출결과_요약.xlsx` 를 지정합니다.

```bash
python -m calc_fee run --raw 로우데이터.xlsx --template 계산파일.xlsx --period "2026년 3분기" --out-dir out/2026Q3 --prev out/2026Q2/산출결과_요약.xlsx
```

`out/2026Q3/` 에 만들어지는 파일:

| 파일 | 용도 |
|---|---|
| `계산파일_결과.xlsx` | 계산파일 양식에 값·수식을 넣은 결과 (원본 양식은 바뀌지 않음, 서식·메모 유지) |
| `검증결과.xlsx` | 검증 요약(정상/주의/오류/생략), 전기 대비, 교차검증 |
| `산출내역_한글용.docx` | 회비 총괄·기관별 실적·기관별 회비 표. 한글에서 열거나 표를 복사해 붙여넣기 |
| `산출결과_요약.xlsx` | 기관별 산출 결과 전체. **다음 산출 때 `--prev` 로 사용** |
| `기관별/` | 기관별 회비 산출내역 엑셀 (메일 첨부용) |
| `피벗_검토.xlsx` | 시트별 피벗 원표, 항목별 합계, 매핑 규칙 |

검증에서 **오류**가 있으면 종료 코드 1을 돌려주고, 메일 발송도 막힙니다.

### 2. 담당자 메일 발송

```bash
python -m calc_fee mail --out-dir out/2026Q3
```

기본은 **미리보기**입니다. 실제로 보내지 않고 `메일/미리보기/*.eml`(메일 프로그램으로 열어 확인)과
`메일/발송목록_미리보기.csv` 만 만듭니다. 확인 후 실제로 보낼 때:

```bash
python -m calc_fee mail --out-dir out/2026Q3 --send
```

- 발송 전에 `발송` 이라고 입력해야 진행됩니다 (`--yes` 로 생략 가능).
- 일부 기관만: `--only 002,003`
- 결과는 `메일/발송결과_날짜시간.csv` 에 남습니다 (발송/실패/제외와 사유).

메일 설정은 `config/mail.toml`(SMTP 서버, 보내는 사람, 제목·본문 양식),
담당자 목록은 `config/contacts.csv`(기관코드, 기관명, 담당자, 이메일, 참조)입니다.
SMTP 비밀번호는 파일에 쓰지 않고 환경변수 `CALC_FEE_SMTP_PASSWORD` 로 넣습니다.

> 저장소의 `config/contacts.csv` 는 `example.com` 주소로 된 **예시**입니다.
> 실제 담당자 연락처는 개인정보이므로 저장소에 올리지 말고 별도 파일로 두고 `--contacts 경로` 로 지정하세요.

## 산출 기준 (config/mapping.toml)

| 블록 | 내용 |
|---|---|
| `[[sources]]` | 로우데이터 시트별 피벗 규칙: 기관코드 열, 제외 열, 항목(→ 계산파일 열) |
| `[code_merge]` | 기관코드 합산 (외환 005 → 하나은행 081 등) |
| `[target]`, `[row_formulas]`, `[totals]` | 계산파일 '1. 실적' 시트 위치와 합계 수식 |
| `[fee]` | 회비 총액, 자동송금 비율(3%), 균등회비 비율(25%), 참가기관 수(64) |
| `[[round_adjust]]` | 단수 조정: 실적 비율 합계 1(0.000001%씩), 실적회비 합계(1원씩), 큰 기관부터 |
| `[summary.groups]` | 기관별 자료·한글 문서에 보여줄 실적 묶음(지로/CMS/펌뱅킹) |
| `[validation]` | 전기 대비 이상치 기준 (기본 ±30%) |
| `[[dummy_fill]]` | **임시** 난수 데이터 (카드이동서비스). 실제 데이터를 쓰게 되면 삭제 |

파일/전문 → 항목 규칙: 앞자리는 업무(AT21xx 신규 / AT31xx·AT36xx 해지 / 3100xx·AT30xx 변경),
끝자리는 서비스(1 지로 / 2 CMS / 3·5·6 펌뱅킹). 예외: Payinfo접수분 → CMS 해지, AT1113 → 펌해지내역중계.

## 검증 항목

- **집계**: 시트별 로우데이터 합계 = 피벗 합계, 계산파일 입력 누락 없음, 펌중계 상세 = 실시간
- **회비**: 실적 비율 합계 = 1, 실적회비 합계 = 실적회비 총액, 기관별 회비 합계 = 자동납부분, 실적 0 기관
- **설정**: 균등회비 기관 수 = 실제 기관 수, 자동송금 비율 = 계산파일 D2, 임시 데이터 사용 여부
- **전기 대비**: 실적·회비 증감률이 기준을 넘는 기관, 신규·제외 기관
- **교차검증**: LibreOffice 로 계산파일 수식을 실제 계산한 값 = 프로그램 계산값 (기관별), 수식 오류(#REF! 등) 없음

## 구조

```
calc_fee/
  __main__.py     실행 명령 (run, mail)
  pivot.py        로우데이터 읽기·피벗·매핑 검사
  workbook.py     계산파일 양식에 값·수식 입력
  xlsx_writer.py  한셀로 저장된 xlsx 를 서식 손상 없이 수정 (시트 XML 직접 편집)
  engine.py       회비 계산 엔진 (계산파일과 같은 순서, 엑셀 반올림 방식)
  validate.py     검증 (내부 정합성, 전기 대비, 교차검증)
  reports.py      요약·검증·기관별 엑셀, 한글용 docx
  mailer.py       담당자 메일 (미리보기 / 발송)
config/           산출 기준, 메일 설정, 담당자 목록
tests/            테스트: python -m unittest discover -s tests -v
```

`data/`, `out/` 폴더는 실제 데이터가 들어가므로 저장소에 올리지 않습니다(.gitignore).
